# Datheon ML Data Science Internship

This repository contains the project work for the internship:

- `Task_1_Classification/` - Classification
- `Task_2_Regression/` - Regression
- `Task_3_Customer_Churn/` - Customer churn

Each task folder includes a Jupyter notebook, a `src/` directory for source
code, and a `results/` directory for generated outputs.
